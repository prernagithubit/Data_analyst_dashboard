# 📊Interactive Data Analysis & Visualization Dashboard using Streamlit

An interactive data analysis dashboard built using Streamlit.

## 🚀 Features
- Upload CSV/Excel files
- Data cleaning (missing values, duplicates)
- Interactive visualizations (Histogram, Bar, Line, Scatter, Box)
- Correlation heatmap
- GroupBy analysis
- Automated insights generation
- KPI metrics display

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas
- Plotly

## 📂 How to Run Locally
git clone https://github.com/prernagithubit/Data_analyst_dashboard.git
cd Data_analyst_dashboard
pip install -r requirement.txt
streamlit run app.py
